## 每道菜怎么写

一道菜一个文件，放在仓库根目录，文件名就是菜名。写完后把链接加进上面的目录。

每份笔记尽量包含这三块：

- **用料**：分量写具体，方便按人数调整
- **步骤**：按实际下锅的顺序写
- **备注**：时间、火候，以及容易翻车的地方
